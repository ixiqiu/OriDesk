## 8. 文件上传有类型与大小校验

| 层次 | 措施 |
|---|---|
| 表单层 | `apps/tickets/forms.py`：单次最多 10 个附件；逐个校验 `max_attachment_bytes()`（来自 `Setting.max_attachment_size_mb`，默认 25MB） |
| 存储层 | `apps/mailboxes/storage.py::store_inbound_attachment` 再次按上限过滤，超限跳过并 `logging.warning` |
| 路径安全 | 文件名/目录名经 `safe_component()` 净化，`absolute_path()` 拒绝 `..` 与绝对路径逃逸（`tests/test_crypto.py` 有专门用例） |
| 危险类型 | `Attachment.is_dangerous`（`.exe/.bat/.js/.scr/.vbs/.cmd/.com/.msi/.jar/.ps1`）→ 禁止在线预览，仅允许下载 |
| 入口层 | `settings.DATA_UPLOAD_MAX_MEMORY_SIZE`（25MB）与 Nginx `client_max_body_size 30M` |
| 附件下发 | 需登录 + 工单可见；生产建议 `ATTACHMENT_X_ACCEL_PREFIX` + Nginx `internal`（见 R-1） |

## 9. 邮箱凭据加密存储，日志不出现明文

- `Mailbox.secret_encrypted`（`BinaryField`）+ `set_secret()` / `get_secret()`（Fernet）。
- 日志与页面只出现掩码或布尔状态：`apps/core/crypto.py::mask_secret`、`Mailbox.secret_masked`、
  后台/前台表单均用 `PasswordInput(render_value=False)`。
- 无任何 `logger.*secret*` / `print(secret)` 语句（grep 结果为空）；`send_reply`/`smtp_send` 出错时
  只输出邮箱地址与 SMTP 主机，不输出凭据。
- 审计明细经 `apps/audit/services.sanitize_detail()` 脱敏（`secret`/`password`/`token` 等键一律写 `***`）。

## 需在部署时显式确认的风险

### R-1 附件目录的对外暴露（已提供默认安全方案）

`/media/attachments/` 若由 Nginx 直出且无鉴权，任何人拿到 URL 即可绕过工单可见性下载附件
（路径含自增 `ticket_id`，枚举成本低）。**当前配置已改为安全默认**：

1. 应用层视图 `apps/tickets/views.py::_serve_attachment` 在鉴权通过后返回
   `X-Accel-Redirect: /media/attachments/<百分号编码路径>`（需在 `.env` 设置
   `ATTACHMENT_X_ACCEL_PREFIX=/media/attachments/`）；
2. `deploy/nginx/ticket.example.com.conf` 中该 location 已设为 `internal;`，匿名直链一律 404；
3. 未设置该环境变量时 Django 自行流式返回文件（功能可用，但会占用 web 进程带宽）。

`/media/`（attachments 之外）仍为直出，仅用于富文本内嵌图片，请勿存放敏感文件。

### R-2 邮件风暴防护依赖"防循环过滤 + 自动回复防重复"

- 单封来信最多触发一条自动回复；自动回复带 `Auto-Submitted: auto-replied`，
  再次入站会被 `filters.is_loop_mail` 丢弃（对称防护，`apps/mailboxes/tests/test_filters.py` 覆盖）。
- 同发件人 N 小时内只发一次（`Setting.first_contact_window_hours`，默认 24）。
- 建议上线后按 `docs/运维手册.md` 的"出站风暴预警阈值"监控 SMTP 发信量，
  一旦异常可用"冻结邮箱 `is_active=0` → 排查 → 再启用"的应急流程。

### 低风险项（已记录，暂不处理）

- 规则里的 `regex` 由管理员维护，存在 ReDoS 理论风险；当前仅捕获 `re.error`（见 `需求实现对照.md` §4.5）。
- 本地开发 `.env` 中的密钥仅供本机使用，未进版本库；生产必须重新生成。
